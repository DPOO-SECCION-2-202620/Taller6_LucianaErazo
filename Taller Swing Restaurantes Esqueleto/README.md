Como ejecutar la aplicación
1. Abrir Eclipse.
2. File → Import → General → Existing Projects into Workspace.
3. Seleccionar la carpeta "Taller Swing Restaurantes Esqueleto" y darle Finish.
4. Abrir la clase 'VentanaPrincipal' (paquete 'uniandes.dpoo.swing.interfaz.principal').
5. Clic derecho → Run As → Java Application.
